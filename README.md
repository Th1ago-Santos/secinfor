# Seção de Informática — 14° B Log

Sistema de Gestão e Controle de Patrimônio de Notebooks e Materiais de Carga.

## 🏗️ Tecnologias

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui + Framer Motion
- Lovable Cloud (banco de dados, autenticação, edge functions)

## 📄 Módulos

- **Dashboard** — KPIs, gráficos e análise de hardware por IA
- **Notebooks** — CRUD com foto, patrimônio, modelo, seção, militar e status
- **Material Carga** — Controle de materiais sob carga da seção
- **Movimentações** — Histórico completo com filtros e exportação
- **Inventário** — Conferência por sessão com validação de patrimônio
- **Prioridades** — Ranking de distribuição com drag-and-drop
- **Mapa de Seções** — Visão geral das seções com barras de status
- **Alertas** — Central de alertas com geração automática e tempo real
- **Impressão** — Visualização pré-impressão com QR Code
- **Pesquisa Global** — Busca unificada em tempo real

## 🔐 Uso

Sistema desenvolvido para uso interno da **Seção de Informática — 14° B Log**.
